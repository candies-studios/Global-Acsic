# Images Directory

Place all image assets in this directory.

## Expected Images

- `acsic-logo-blue-gold.png` - Main conference logo (used in header and footer)

## Image Guidelines

- Use PNG format for logos and icons (supports transparency)
- Use JPG/JPEG format for photographs
- Optimize images for web (reduce file size)
- Recommended dimensions:
  - Logo: 200x60px (header) to 150x50px (mobile)
  - Hero/Section images: 1200x600px
  - Card images: 400x300px

## How to Add Images

1. Place image files in this directory
2. Reference in HTML using relative paths: `../assets/images/filename.png`
3. Always include alt text for accessibility
